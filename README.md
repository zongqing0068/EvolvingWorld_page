# EvolvingWorld Project Page

This repository hosts the project page for **EvolvingWorld: An Open-Schema Framework for Co-Evolving Role-Play Agents and World Model in Interactive Literary World** (EMNLP 2026).

EvolvingWorld studies long-horizon interactive literary world simulation. Its Character Agent and World Model maintain evolving character and world states across interactions, with open-schema representations and a Hidden Tracker for changes at different timescales.
